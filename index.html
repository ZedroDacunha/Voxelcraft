Sobre o Voxelcraft

Uma aventura em blocos em primeira pessoa, feita para jogar direto no navegador.

Controles básicos

WASD para mover, mouse para olhar, botão esquerdo para quebrar, botão direito para colocar/usar, E para inventário, Esc para pausar.

Créditos

Voxelcraft é um projeto experimental de jogo voxel na web. Feito com JavaScript e Three.js.
