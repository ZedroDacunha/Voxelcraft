# Documentação do Voxelcraft

Toda a documentação **datada** do projeto mora aqui, para a raiz do repositório
ficar só com o código e com os documentos de referência permanente
(`README.md`, `GUIA-DE-ARTE.md`, `TESTE-EM-NAVEGADOR.md`).

| Pasta | Tipo | Padrão de nome |
| --- | --- | --- |
| [`melhorias/`](melhorias/) | Melhorias de interface, polimento e conteúdo | `MELHORIA-AAAAMMDD-*.md` |
| [`bugs/`](bugs/) | Bugs corrigidos: sintoma, causa, correção, validação | `BUG-AAAAMMDD-*.md` |
| [`testes/`](testes/) | Cobertura de teste nova e o que ela passou a verificar | `TESTES-AAAAMMDD-*.md` |
| [`analises/`](analises/) | Análises, diagnósticos e revisões gerais | `ANALISE-*`, `DIAGNOSTICO-*`, `REVISAO-*` |

O roteiro de verificação manual em aparelho de verdade continua em
[`TESTE-EM-NAVEGADOR.md`](../TESTE-EM-NAVEGADOR.md), na raiz, e as regras de
arte em [`GUIA-DE-ARTE.md`](../GUIA-DE-ARTE.md).
